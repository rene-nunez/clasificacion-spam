# Avisos de terceros

Este repositorio incluye y utiliza componentes de terceros que se detallan a continuación.

## Dataset: synthetic-spam-detection-dataset-spanish

- **Autor:** Tanaos
- **Fuente:** <https://huggingface.co/datasets/tanaos/synthetic-spam-detection-dataset-spanish>
- **Licencia:** MIT

El dataset se descarga en tiempo de ejecución mediante `src/descargar_datos.py` y no se redistribuye dentro de este repositorio. Los modelos entrenados a partir de él son obras derivadas de los datos y se distribuyen bajo la licencia Zlib de este proyecto, conservando la atribución anterior.
